# Version 1 Requirements

## Objective

Build a safe 4WD indoor mobile robot with Raspberry Pi,
ESP32 motor control, LiDAR, camera, MCP tools, and a web dashboard.

## Version 1 capabilities

- Manual web-dashboard control.
- Motor movement through ESP32.
- Encoder feedback.
- LiDAR scanning.
- Camera capture.
- Obstacle detection.
- Emergency stop.
- Event logging.

## Version 1 exclusions

- Voice control.
- Display.
- Second camera.
- TOF sensor.
- Full autonomy.
- ROS 2 navigation.
