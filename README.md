# Saras Robot

Version 1 indoor AI mobile robot prototype.

## Objective

Build a safe 4WD mobile robot using an ESP32 motor controller, Raspberry Pi 5, LD06 LiDAR, camera, MCP tools, and a web dashboard.

## Current stage

Phase 0: requirements, procurement, architecture, and repository setup.

## Main systems

- ESP32 motor and encoder controller
- Raspberry Pi 5 robot computer
- LD06 360-degree LiDAR
- Raspberry Pi Camera Module 3 Wide
- FastAPI web dashboard
- MCP hardware tools
- Ollama and Claude Code development workflow
